# WDA — Web Dev Assets

> A curated repository of reusable **React & Next.js UI components**, usage examples, and reference snippets built for fast development and AI-assisted workflows.

---

## ✨ What’s Inside

* **UI Components:** Ready-to-use React / Next.js components organized by category and variant.
* **Usage Examples (`usage.tsx`):** Practical examples showing how components are imported and wired up.
* **Dependencies & Notes:** Clear notes on required packages (`npm install ...`), styling, and client/server behavior.

---

## 📁 Folder Structure

```text
components/
└── <category>/          # e.g., navbar
    └── <variant-name>/    # e.g., minimal-navbar
        ├── Component.tsx
        ├── usage.tsx
        ├── style.css
        └── notes.md
```
<h2>🚀 How to Use</h2>
​1. Pick a component variant from its folder and check notes.md for any required dependencies.<br>
​2. Install dependencies in your target project if needed.<br>
​3. Copy & adapt the component code and usage.tsx into your project paths (@/components/...).
--- 
​<h2>🤖 AI Reference Workflow</h2>

This repository is structured to act as a clean reference source for AI coding tools and local models:

* Consistent folder and file naming so components and variants stay separated.
* Usage snippets included alongside component definitions to reduce prop or import mistakes.
* Dependency notes kept explicit so required packages aren't missed.
